# Green Forest Pokemon

A terminal-based Pokémon battle game. Your character `@` has to cross the forest and defeat every enemy `*` on the way.

The program uses different classes to start battles against different enemies. It displays messages during each fight, keeps track of your victories depending on the results, and shows your final score at the end of the map.

## Requirements

- Python 3.x
- [`readchar`](https://pypi.org/project/readchar/) (installed in the steps below)

## Install and try

1. Clone the repository:

```bash
git clone https://github.com/ignaciocantero94/Green_Forest_Pokemon.git
cd Green_Forest_Pokemon
```

2. Install dependencies:

```bash
pip3 install -r requirements.txt
```

3. Run the game:

```bash
python3 green_forest.py
```
> **Note:** run it from a regular terminal, not from an editor's built-in console, since `readchar` may not work there.

## Controls

- W / A / S / D: move
